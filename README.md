# Runlist

Start, stop, and switch local apps from one sidebar.

<img src="media/gallery-01-hero.png" width="1280" alt="Every local app in one VS Code sidebar">

- Every local app, one place
- Save the start command once
- See what’s running — stop or restart from the row
- Open the app when it’s ready
- Switch cleanly when a port is already in use

## Get started

1. Open the Runlist sidebar
2. Add this folder
3. Save the start command — or pick a `start` / `dev` chip when your folder already has one
4. Start it from the list

<img src="media/gallery-02-status.png" width="1280" alt="See what’s running and open it from here">

See what’s running. Stop it, restart it, or open it from here.

First-run stays empty until you add a folder. No setup dump.

## Everyday use

- Start, stop, and restart from the project row
- Open the app from the port chip — with clear status and how long it’s been running
- Checks configured ports before Start, and helps you switch when another Runlist app owns the port
- Live preview and recent output while you work
- Open on phone for local web apps on your network
- Search, pin favorites, open the folder in VS Code, or open a terminal here
- Windows, macOS, and Linux

## Also included

- **Launch profiles, tags, and groups** — keep alternate commands handy, filter the list, and start related apps together
- **More menu (⋯)** — Set Up Agents, Import or Export, Load stack, Manage groups, and What’s Listening
- **Load stack** — bring in a shared project setup from the repo, review it, then start when you’re ready
- **Docker Compose import** — review services first; nothing starts until you press Start
- **Optional env file** on a launch profile — attach a local file so Start has what it needs
- **Optional local hostname** — open as `name.localhost` when it fits; otherwise fall back to `localhost`
